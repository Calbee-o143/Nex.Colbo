# nex.colbo

A lightweight, static web browser built with HTML, CSS, and JavaScript, featuring an embedded DuckDuckGo browsing experience.

## Overview

nex.colbo is a simple, browser-based interface designed to provide a clean and minimal way to access the web. It uses an iframe to display DuckDuckGo within the website.

## Features

- Static website — No dedicated backend required.
- Embedded browser — Displays DuckDuckGo through an iframe.
- Minimal interface — Simple, clean design.
- Lightweight — Built with standard web technologies.
- Easy deployment — Can be hosted on Vercel, GitHub Pages, or other static hosting platforms.

## Technology

- HTML5
- CSS3
- JavaScript
- HTML iframe
- DuckDuckGo

## Deployment

1. Upload the project files to your GitHub repository.
2. Connect the repository to Vercel or another static hosting provider.
3. Deploy the website.
4. Open the deployed URL to use nex.colbo.

## Limitations

DuckDuckGo may block iframe embedding or restrict certain features because of its security policies. Website compatibility depends on the external website's iframe permissions and browser restrictions.
